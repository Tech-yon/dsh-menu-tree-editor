# 记事（DSH 插件）

一个用于 DSH Web UI 的「菜单树 + 笔记本」工作台。侧边栏入口名为 **记事**：

- 默认打开 **笔记本**：文件组、搜索、更新历史、撤销删除、本地文件关联、备份导入导出
- 点击右上角 **高级菜单** → **工具** → **多级菜单树**，打开原来的树状菜单编辑器

## 功能

### 笔记本

- 记事列表：标题、正文预览、更新时间、文件组标签
- 文件组：新建、重命名、归档、删除、恢复；把记事卡片拖到文件组即可归类
- 编辑：标题 + 多行正文，停止输入约 1.5 秒自动保存
- 更新说明：每次保存可以填写本次更新说明，底部展开 **更新历史**
- 搜索：标题、正文、更新历史和日期
- 归档 / 删除：删除后弹出「撤销」提示；焦点不在编辑区时按 `Ctrl+Z` 可恢复最近删除（最多 20 条）
- 本地文件：关联 txt/md 等文本文件，`Ctrl+S` 同步写回；也可以「另存为」新的本地文件
- 导入：拖入本地文本文件自动生成记事，或导入 JSON 备份
- 导出：一键导出全部记事和文件组为 JSON 备份
- 所有数据同时持久化在浏览器 `localStorage`，刷新不丢

### 多级菜单树（高级菜单 → 工具）

- 双击模块编辑文字；从任意模块继续添加子模块
- 拖动模块移动，子模块跟随整棵子树
- 整理布局、撤销/重做、复制/粘贴、删除
- 本地文件夹：选择任意目录，读取/保存 `.json` 菜单文件，新建文件/子文件夹，自动保存
- 导出 JSON、Markdown 大纲、Mermaid、PNG、SVG
- 滚轮缩放，拖动空白处平移

## 安装

DSH 插件以 Bundle 形式安装。把这个目录安装到你的 DSH profile：

1. 在插件管理器中选择本目录作为本地 bundle 安装，或安装 GitHub 地址：
   `github:Tech-yon/dsh-menu-tree-editor`
2. 启用插件。
3. 重启 DSH（Host 端本地文件接口在启动时注册），刷新页面。

侧边栏会出现「记事」入口。

## 使用

1. 点击侧边栏「记事」，默认进入笔记本。
2. 点击右上角「高级菜单」：
   - **笔记本**：记事本
   - **工具 → 多级菜单树**：树状菜单编辑器
3. 笔记本第一次打开会带一篇欢迎说明，可直接删除。

### 快捷键

笔记本：

| 操作 | 快捷键 |
|---|---|
| 保存 | `Ctrl+S` |
| 撤销删除（焦点不在输入区） | `Ctrl+Z` |
| 编辑区内文本撤销/重做 | 浏览器原生 `Ctrl+Z` / `Ctrl+Y` |

菜单树：

| 操作 | 快捷键 |
|---|---|
| 编辑选中模块 | `Enter` / `F2` |
| 保存 | `Ctrl+S` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 复制 / 粘贴 | `Ctrl+C` / `Ctrl+V` |
| 删除 | `Delete` |

## 文件与数据

- 菜单树文件：用户选择的本地文件夹中的 `.json`；未选择时回退到 DSH 工作区 `menu-tree/`
- 笔记本数据：浏览器 `localStorage`，键 `dsh:menu-tree-editor:notes:v1`
- 笔记本备份：导出的 JSON 包含 `groups` 和 `notes`

## 结构

- `index.js` — Host 半：本地文件夹文件接口（列表/读取/保存/新建目录），受 DSH 认证保护
- `client.js` — Client 半：记事应用外壳、高级菜单、笔记本、菜单树
- `cordis.patch.yml` — Bundle patch，插入 Host 行
- `locale/*.json` — 插件显示名称/描述
- `icon.svg` — 插件图标

## 开发

```bash
node --check index.js
node --check client.js
```

Host 端修改需要重启 DSH；Client 端刷新页面即可。
